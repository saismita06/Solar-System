# 3D Solar System – Saismita Jena

## 📋 Features
- Sun + 8 Planets orbiting
- Speed control for each planet
- Responsive layout

## 🚀 How to Run
1. Download or clone the repo
2. Open `index.html` in any modern browser
3. Adjust planet speed using sliders

## 📦 Tools Used
- Three.js
- HTML/CSS/JavaScript only (no frameworks)
